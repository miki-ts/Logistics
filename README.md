# YM Logistics Complete Website

A connected multi-page static website built from the provided YM Logistics UI designs.

## Pages
- `/` — Home
- `/about/` — About
- `/services/` — Services
- `/team/` — Team
- `/contact/` — Contact
- `/quote/` — Request a Quote

All navigation and Request Quote buttons are connected between pages. Each page uses one navigation bar.

Open `index.html` to start the website.
